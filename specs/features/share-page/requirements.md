# 分享页 — 需求

## 背景与目标

用户打开一条已完成的历史对话时，消息内容、引用来源、工具调用结果都已经落库，是纯静态数据。分享页要把这样一条对话以可被外部抓取、秒开的形式呈现出来。它是整个应用里 SSR 收益最明确的场景之一，也是 Web target 相对于 Electron 和扩展独有的价值所在。

## 用户故事

作为一个想把对话分享给他人的用户，我希望生成一个分享链接，链接被打开时对方无需登录就能看到完整的对话内容，并且在社交平台粘贴时能出现预览卡片。

作为搜索引擎或链接预览抓取器，我希望在不执行 JavaScript 的情况下就能拿到对话的标题、摘要和主体 HTML。

## 验收标准

分享链接对应一条已定稿的对话，首屏由服务端直出完整 HTML，无需等待客户端二次请求即可看到全部消息、引用来源和工具调用结果。

页面包含可供抓取的元信息（标题、摘要、Open Graph 卡片），在不执行 JavaScript 的环境下主体内容仍可读。

分享页只呈现静态定稿内容，不包含实时生成、编辑或再对话的交互能力；如需继续对话，引导用户进入应用主流程。

未授权或已失效的分享 token 返回明确的失效提示，不泄露任何对话内容。

## 非目标

不覆盖对话的实时生成过程，那属于 agentic-stream 功能。不覆盖 Electron 和扩展端——它们没有外部抓取和秒开诉求，历史数据客户端拉取即可。
